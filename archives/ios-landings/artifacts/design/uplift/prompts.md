# Preview generation prompt set

Tool: built-in `image_gen.imagegen`, one call for each proposal, with `transparent_background: false` and `products/kith/public/images/screens/constellation.webp` as the reference image. Original generated files are retained; workspace copies are `a-tactile.png`, `b-constellation.png` and `c-memory.png`.

## Shared prompt

Use case: ui-mockup. Create a polished high-fidelity DESIGN PROPOSAL image of a desktop landing website for Kith, a private iPhone relationship-memory app. This is a whole-page art-direction comp, not a generic SaaS template. Show the first viewport and a meaningful second-fold scene. Portrait 1024x1536 composition, website at desktop proportions, crisp readable typography. Use the referenced real Kith constellation screenshot as the exact product evidence inside one iPhone with preserved content. Do not fabricate additional app screens. Keep core copy verbatim: brand "Kith"; eyebrow "Private relationship memory for iPhone"; heading "Remember the people you want to stay close to."; supporting sentence "A place for how you met, what matters now, and the moments you want to keep."; primary action "See beta status"; small status "Internal TestFlight only. No public invite."; second section heading "See them. Remember. Add the moment." No App Store badge, testimonials, metrics, prices, sales CRM or message reminders. Clearly distinguish expressive art from the actual app screenshot. Clean professionally typeset interface with a memorable composition and generous typography.

## Inspection notes

All three files are 1024x1536 and were visually inspected. Generated comps approximate the reference screenshot; final implementation must insert the original image directly rather than publish the generated phone pixels. A omitted the direction label, which is supplied in the comparison page. C uses some serif body text despite the sans direction; final typography will follow the selected system. Decorative copy in the generated art is concept material and will be reviewed before any production use. Core interface text and actions will remain semantic HTML.
